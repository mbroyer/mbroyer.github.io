Fotografier Vokabelliste, Buchseite oder Hausaufgabe, und daraus wird dein eigenes Vokabeltraining. Mit Monstern, die mitwachsen.

Gut zu wissen

Brauche ich einen Code?

Zum Ausprobieren nicht: Die Demo läuft eine Runde lang ohne Code. Wer weiterüben will, bekommt einen Code von Mark. Code anfragen

Wird etwas gespeichert?

In der Demo nichts. Mit Code bleibt dein Fortschritt gespeichert, auf jedem Gerät, auf dem du dich anmeldest.

Mit welchen Vokabeln übe ich?

Mit deinen eigenen: Fotografier eine Vokabelliste oder Hausaufgabe, oder wähle die Seiten aus deinem Buch.

Auf welchen Geräten läuft Vokamon?

Im Browser auf Handy, Tablet und Computer. Installieren muss man nichts.
